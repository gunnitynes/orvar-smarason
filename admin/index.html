First-time setup

This is done once. After it, signing in only takes the password, on any computer or phone.

The site's text and pictures are stored on GitHub, so the editor needs a GitHub access key (a "token"). It is locked with your password and saved with the site; only the password can open it.

Account and repository are filled in for you. Only change them if the site has been moved.

How to get a token

  1. Log in to github.com with the account that owns this site.
  2. Open Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Under Repository access choose Only select repositories and pick this site's repository, and nothing else.
  4. Under Permissions press Add permissions, type contents in the search box and tick Contents. Then change its access from Read-only to Read and write.
  5. Pick the longest expiry on offer, generate the token, copy it, and paste it above.

When the token expires, signing in stops working. Make a new token and run this setup again.
